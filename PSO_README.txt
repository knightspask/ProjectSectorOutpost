# ProjectSectorOutpost
Project SectorOutpost is a project I plan to work on a base for creating new weapons, items, health, random item boxes, world building of Doom1 and Doom2 world where the map will be made from scratch while keep the world grounded to how it will be played in game as you can venture back and forth in the map.

Credits for Davidxn for creating the BDLite version and Sergeant Mark IV for the awesome brutal Gore for all the monsters and players in game as an inspiration, so to be clear, all of this will be placeholder for the use of this project till I 3d render and replace them or sprite them by hand so this will not be overnight so bare with me, I will be changing sounds, menus, sprites graphics and many more to come.

For the time being I am going to work on replacing the weapon sprites for now, just to get a head start on this project so, any changes being made, you will see the  status of the Todo list as its changes over time so keep an eye on that as I contine commit those changes.
